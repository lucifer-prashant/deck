  FEATURES IMPLEMENTED
  ─────────────────────
  • Dynamic theming engine — UI chrome, status bars, panels and text all
    react live to the canvas background colour. Brightness is computed via
    HSP perceptual model and 20+ CSS custom properties are set dynamically.

  • Live colour-picker preview — moving around in the colour picker now
    instantly reflects on the canvas background in real time (no lag,
    throttled to RAF).

  • Manually editable slider values — every number slider in Preferences
    (font size, opacity, blur, snap, zoom speed, etc.) now has an inline
    editable number input next to it.

  • Grid spacing slider — a new "Grid Spacing" slider appears in Preferences
    when the canvas background type is set to "grid" (dots/lines/cross).

  • Saved custom colour presets — 4 built-in premium presets added:
      · Deep Blue     (#0d1b2a)
      · True Black    (#000000)
      · Pure White    (#ffffff)
      · Creamy Pearl  (#f5f0e8)
    Each preset ships with curated accent/selection colours.

  • Shortcut labels now wrap instead of truncating — shortcut names in
    Preferences were being cut off as "…". They now word-wrap up to 2 lines
    so you can actually read what you're binding.

  • Keystroke blocking in overlays — while any overlay (Settings, Command
    Palette, Panel Finder, Help, Win+Tab, Jump mode) is open, canvas
    shortcuts no longer fire. Tab key no longer accidentally triggers jump
    mode while typing in search boxes.

  • Status bar & chrome border contrast — when the canvas background is a
    highly saturated colour (e.g. red), the chrome now renders distinguishing
    borders derived from the bg colour with guaranteed contrast.

  • Preferences readability fixes — "Canvas Background & Panel Styling" and
    other headers in Preferences now use proper CSS variable colours that
    remain legible across all canvas bg colours including white and red hues.

  • Removed ghost button — orphaned/dead button removed from the status bar.

  • Removed ThemeMenu component — the Ctrl+Shift+T theme cycling menu was
    removed (it conflicted with canvas bg and is replaced by the live
    colour system).

  • WinTabSwitcher improvements — better visual polish, improved MRU
    behaviour.

  • DrawingCanvas — major refactor with improved tool handling.

  • AnnotationLayer — CSS and component improvements.

  • Outliner — visual and functional improvements.

  🔴 CONFIRMED BUGS
────────────────────────────────────────────────────────────────────────────────

  BUG-001  [RESOLVED ✓] UNDO MAKES TABS APPEAR DIRTY
           undo() calls syncActiveTab() which sets lastEditedAt = Date.now().
           Undoing back to original state still shows "unsaved changes" badge.
           File: src/store/workspaceStore.ts ~L639
           Fix: pass skipDirty flag when calling syncActiveTab from undo/redo.

  BUG-002  [RESOLVED ✓] [data-theme="system"] CSS IS BROKEN
           The system theme only sets color-scheme: dark light but provides
           zero CSS variable overrides. Light-OS users always get dark theme.
           File: src/App.css ~L107-109
           Fix: add full variable set under a prefers-color-scheme: light block
           or resolve it properly in JS before paint.

  BUG-003  [RESOLVED ✓] LIGHT THEME SCROLLBAR INVISIBLE
           Scrollbar thumb is rgba(255,255,255,0.08) — invisible on white bg.
           No [data-theme="light"] override exists for scrollbar styles.
           File: src/App.css ~L498-506
           Fix: add [data-theme="light"] ::-webkit-scrollbar-thumb override.

  BUG-004  [RESOLVED ✓] REGION ID COLLISION POSSIBLE
           Region IDs use 'region-${Date.now()}' with no random suffix.
           Tab IDs have a random part but region IDs don't. Two rapid region
           creations in the same millisecond produce duplicate IDs.
           File: src/store/workspaceStore.ts ~L1382
           Fix: use crypto.randomUUID() or append Math.random().toString(36).

  BUG-005  [RESOLVED ✓] KEYBOARD HANDLER RE-ATTACHES ON CANVAS BG COLOR CHANGE
           prefs.canvasBgColor and prefs.canvasGridStyle are in the keyboard
           handler's useEffect dep array for no reason. Every colour picker
           interaction re-registers the entire 490-line keyboard listener.
           File: src/App.tsx ~L740
           Fix: remove unrelated prefs from keyboard handler dep array.

  BUG-006  [RESOLVED ✓] BACKDROP-FILTER BLUR INCONSISTENCY IN JUMP OVERLAY
           -webkit-backdrop-filter: blur(6px) vs backdrop-filter: blur(1px)
           in the same rule. One of these is wrong.
           File: src/App.css ~L628-629

  BUG-007  [RESOLVED ✓] webview TAG NAME CASE CHECK
           target?.tagName === 'WEBVIEW' should be target?.tagName?.toLowerCase()
           === 'webview' for cross-platform safety.
           File: src/App.tsx ~L282

  BUG-008  [RESOLVED ✓] UNDO / GRAVEYARD UNSAFE CAST
           Graveyard stores Partial<Panel> but is cast to Panel on restore.
           Missing required fields (x, y, width, height, type) on a graveyard
           entry could crash the canvas silently.
           File: src/store/workspaceStore.ts ~L956

  BUG-009  [RESOLVED ✓] loadPreset() HAS UNHANDLED PROMISE REJECTION
           Dynamic import('../presets') has no .catch(). If the module fails
           to load, the rejection is silent and the canvas just does nothing.
           File: src/store/workspaceStore.ts ~L851-981

  BUG-010  [RESOLVED ✓] dualStorage.setItem HAS ZERO DEBOUNCE
           Writes to disk on every single state change including while
           dragging a panel pixel-by-pixel. Hammers the filesystem constantly.
           File: src/store/workspaceStore.ts ~L52-68
           Fix: debounce file writes by 300-500ms.

  BUG-011  [RESOLVED ✓] AUTO-SAVE ON CLOSE CREATES ACCUMULATING PRESETS
           On app close, saveCanvasPreset(t.title || 'Canvas') creates a NEW
           preset for every unsaved tab silently. After enough sessions the
           Presets panel fills up with "Canvas", "Canvas (1)", etc.
           File: src/App.tsx ~L98-100

  BUG-012  [RESOLVED ✓] MIDNIGHT THEME UNREACHABLE FROM UI
           [data-theme="midnight"] is fully defined in CSS with all variables
           but no Preferences toggle exposes it.
           File: src/App.css ~L69-83

  🟡 IMPROVEMENTS (Missing but High Impact)
────────────────────────────────────────────────────────────────────────────────

  IMP-001  VIEWPORT BOOKMARK UI
           Bookmarks (Ctrl+Alt+1-9 save, Alt+1-9 load) exist but there is
           zero visual indicator that any are set. Could show numbered dots
           on the minimap or a status bar chip.

  IMP-002  MIDNIGHT THEME TOGGLE IN PREFERENCES
           All CSS variables already built. Just needs a UI option.

  IMP-003  SINGLE INSTANCE LOCK
           Multiple Deck instances can run and fight over the same store file.
           app.requestSingleInstanceLock() is one line in electron/main.ts.

  IMP-004  WINDOW SIZE / POSITION PERSISTENCE
           Window dimensions and position reset every launch. Should save to
           electron-store or a simple JSON config on close/resize.

  IMP-005  NATIVE NOTIFICATIONS
           Terminal command finishes, git push completes, build done — none
           of these surface as system notifications. Electron's Notification
           API is right there.

  IMP-006  AUTO-UPDATE (electron-updater)
           No electron-updater installed. Users must manually find and
           download new versions. Even a "update available" banner would help.

  IMP-007  SYSTEM TRAY
           App cannot minimize to tray. Common expectation for always-running
           dev tools.

  IMP-008  ALIGNMENT GUIDE COLOR HARDCODED
           Snap alignment guides are always hot-pink (#ff66cc) regardless of
           theme or canvas bg. Should auto-contrast against the bg colour.
           File: src/App.css ~L591

  IMP-009  CANVAS CURSOR CONTEXT
           cursor: grab is always active on the canvas even in annotate mode
           or when an input is focused. Should switch to crosshair/text/default
           contextually.
           File: src/App.css ~L523

  IMP-010  FOCUS NOT RESTORED AFTER OVERLAY CLOSE
           Closing Settings, Command Palette etc. doesn't return focus to the
           previously focused element. Keyboard users are left stranded.

  IMP-011  CODE-SERVER RUNS WITH --auth none
           Any process on localhost (or LAN) can access code-server. Should
           at minimum surface a warning in the UI or generate a session token.

  IMP-012  PROGRESS BAR ON WINDOW TASKBAR
           win.setProgressBar() for git fetch/pull, code-server start, file
           search — a tiny Electron feature that feels very pro.

  IMP-013  GLOBAL SHORTCUTS
           Register a system-wide shortcut (e.g. Ctrl+Alt+D) to focus Deck
           even when it is not in focus. Electron supports this natively.

  IMP-014  RECENT DOCUMENTS
           app.addRecentDocument() integration + an MRU list on the empty
           state or OS file menu.

  IMP-015  JSON SCHEMA FOR KEYBINDINGS EDITOR
           "Edit JSON (Monaco)" for keybindings is cool but has no JSON schema
           validation or autocomplete for valid command IDs.

  IMP-016  TERMINAL SCROLLBACK IN PREFERENCES
           terminalScrollback (10000 lines default) is not exposed in the UI.
           Power users want to tune this.

  IMP-017  EXPORT CANVAS TO IMAGE/PDF
           webContents.capturePage() could screenshot the visible viewport or
           all panels — useful for sharing a canvas state.

  IMP-018  DEVTOOLS ENABLED IN PRODUCTION
           devTools: true in BrowserWindow config. Should be guarded by isDev.
           File: electron/main.ts


────────────────────────────────────────────────────────────────────────────────
  🟢 IDEAS (Architecture & Polish)
────────────────────────────────────────────────────────────────────────────────

  IDEA-001  CENTRALIZE ALL MAGIC NUMBERS INTO constants.ts
            These are all currently hardcoded scattered across files:
            · Jump mode timeout: 280ms
            · kbd-moving class timeout: 160ms
            · Alt+Arrow resize step: 20px (should match prefs.snapStep)
            · Ctrl+Arrow move step: 20px / 80px (shift)
            · Viewport pan step: 80 / 240
            · Spatial nav lateral penalty: 1.8
            · Panel history limit: 80
            · Annotation history limit: 60
            · MRU cap: 20
            · PTY scrollback cap: 256KB
            · Viewport fit padding: 96px
            · Default panel sizes: 600×400, 1100×760, 720×560
            · Z-indices: 6000, 9999, 11000, 11500

  IDEA-002  Z-INDEX SCALE SYSTEM
            All z-index values are magic numbers with no system. Define:
            --z-panel, --z-overlay, --z-modal, --z-top as CSS variables
            with explicit ordering documentation.

  IDEA-003  SPLIT workspaceStore.ts INTO SLICES
            At 1921 lines / 80KB it is one giant file. Split into:
            panelSlice, annotationSlice, tabSlice, presetSlice,
            keybindingSlice, viewportSlice. Zustand supports slice pattern.

  IDEA-004  LAZY LOAD HEAVY PANEL TYPES
            Monaco Editor + xterm.js are very heavy. React.lazy + Suspense
            for EditorPanel and TerminalPanel could save 1-2s startup time.

  IDEA-005  USE crypto.randomUUID() EVERYWHERE FOR IDS
            Tab IDs use Date.now() + partial Math.random(). Region IDs just
            use Date.now(). Replace all with crypto.randomUUID() which is
            available natively in Electron/Chromium.

  IDEA-006  DEBOUNCE dualStorage FILE WRITES
            Currently writes on every state mutation including drag. Add a
            300-500ms debounce so file I/O only happens on settle.

  IDEA-007  SPLIT 490-LINE KEYBOARD HANDLER IN App.tsx
            The single useEffect keyboard closure is 490 lines. Break into
            focused handlers: jumpModeHandler, viewportNavHandler,
            panelOpsHandler, shortcutDispatchHandler.

  IDEA-008  ARIA LANDMARKS & FOCUS MANAGEMENT
            Root <div className="app"> has no ARIA landmarks. No skip
            navigation link. Overlays don't return focus on close.
            Chrome peek button content is just a triangle character.

  IDEA-009  NO TESTS AT ALL
            Zero test files in the entire codebase (no jest, vitest,
            playwright, electron-testing-library). Even basic smoke tests
            for the store actions would catch regressions.

  IDEA-010  UPDATE XTERM PACKAGES
            xterm 5.x package was renamed to @xterm/xterm. The old npm
            package is essentially abandoned. Same for addons:
            xterm-addon-fit → @xterm/addon-fit
            xterm-addon-webgl → @xterm/addon-webgl

  IDEA-011  UPDATE ELECTRON (28 → 35+)
            Electron 28 is several major versions behind. Newer versions
            include security patches, better V8, improved GPU stack,
            better Apple Silicon support, and new APIs.

  IDEA-012  dualStorage CONFIG PATH IS LINUX-ONLY
            ~/.config/deck/ is hardcoded as a string. Should use
            Electron's app.getPath('userData') passed from main via IPC
            so it works correctly on macOS and Windows too.

  IDEA-013  SESSION STATS WIDGET
            Time spent, panels opened, commands run — small status bar
            chip or sidebar widget. Feels premium and personal.

  IDEA-014  FOCUS MODE PER TAB
            Hide all panels except selected ones — presentation / review
            mode. Toggled per-tab, not globally.

  IDEA-015  HIGH CONTRAST THEME
            No forced-colors or prefers-contrast media query support.
            Windows High Contrast mode users get broken UI.
